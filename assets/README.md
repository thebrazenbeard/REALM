# REALM social-preview image

`realm-social-preview.jpg` is AI-generated **concept art** for the GitHub
repository's social preview, resized to 1280×640. It is not a screenshot of
gameplay, a promise of 3D graphics, or a worldpack asset. REALM gameplay is
text-only. The lettering identifies the intended product: Roleplaying Engine
for Autonomous Living MUDs.

Adding this JPEG to the repository does **not** automatically configure GitHub's
social preview. The owner must upload it separately through Repository Settings
→ General → Social preview → Edit. This text is a provenance note for a
newly generated project graphic, not an independent intellectual-property
clearance certificate.
