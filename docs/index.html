Command reference — chat, roleplay & PvP

Examples only. Commands run after you connect to an authorized host; available features depend on that world. Type help for its full list.

  • emote wavesDescribe an action to characters in your current room.
  • ooc helloOut-of-character chat across the current world.
  • crewchat helloPrivate group chat; requires host-granted membership.
  • pvp statusCheck your PvP opt-in and health state.
  • pvp onOpt in to host-enabled PvP. Use pvp off to opt out.
  • attack PlayerOnly for same-room, opted-in players when host rules and presence checks allow combat.
